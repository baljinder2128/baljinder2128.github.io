KICKOFF DOCS - standalone app
=============================
Make or convert PDF, Word, Excel, PowerPoint, CSV and Markdown files.
Everything runs on your own device. No internet needed after install,
and your files are never uploaded anywhere.

QUICK TRY ON A COMPUTER (no install)
  Unzip, then double-click index.html. It opens in your browser and works offline.

INSTALL AS AN APP (iPhone, Android, Windows, Mac)
  The app has to be on a website (https) once so phones can install it.
  Free and easy: https://app.netlify.com/drop
    1. Unzip this file.
    2. Drag the whole "kickoff-docs-app" folder onto the Netlify Drop page.
    3. You get a link like https://something.netlify.app
  (GitHub Pages or Cloudflare Pages work the same way.)

  Then open that link and install:
    iPhone / iPad (Safari):  Share button -> "Add to Home Screen"
    Android (Chrome):        menu (three dots) -> "Install app" / "Add to Home screen"
    Windows / Mac (Chrome or Edge): install icon at the right of the address bar
    Mac (Safari 17+):        File -> "Add to Dock"

  After the first open it works fully offline and has its own icon.

SAVING FILES
  Computer / Android: files go to your Downloads folder.
  iPhone / iPad: a share sheet opens. Choose "Save to Files".

UPDATING THE APP LATER
  Replace the files on your host and change VERSION in sw.js
  (for example kickoff-docs-v2) so installed copies pick up the new version.

Open-source libraries and fonts used are listed with their licences in /licenses.
